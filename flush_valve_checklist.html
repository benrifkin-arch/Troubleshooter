Flush Valve Diagnostic Checklist

Selectronic® Ultima WC & Urinal

Parts Reference Diagram

Initial Information  (Required for all scenarios)

Unit Does Not Function  (No Flush)

Start here if valve does not flush at all — sensor OR manual
Is the supply stop fully open?
→ If NO: Open stop one full rotation WHILE holding the manual override button, then release
→ Does unit now flush?   ☐ Yes — continue to next step   ☐ No → Replace Manual Override Button  M970784-0020A
Is there a Repeated Double Flash on the sensor LED?
→ If YES (double flash): Test voltage at power supply. Is reading < 6V DC?
→ ☐ Yes < 6V → Replace Power Supply (PK01-HAC or PK01-PAC) or Battery
→ ☐ No ≥ 6V → Is wiring distance > 10 ft or has wiring been extended?  ☐ Yes → Check / shorten wiring run
Disconnect & reconnect power supply for 10 seconds
Does sensor flash for 5 seconds after reconnecting?
→ If NO: Replace Power Supply or Battery. Issue resolved?  ☐ Yes  ☐ No →
→ Inspect wiring for breaks / corrosion. Replace Sensor (see GPF # below). Issue resolved?  ☐ Yes  ☐ No → Escalate
Push Manual Override button — does unit flush?
→ ☐ Yes → Inspect piston & o-ring. Replace Solenoid & Piston Assembly  M970694-0070A
→ ☐ No  → Replace Manual Override Button  M970784-0020A

Continuously Flushing  /  Running

PRIME VALVE: Close supply stop, then reopen WHILE holding the manual override button. Release button.
Does unit STOP flushing when the manual button is released?
→ If YES (stops on release): Disconnect & reconnect power supply for 10 sec → continue to sensor flash check
→ If NO (keeps flushing): Push manual override. Does button return to original position freely?
→ ☐ No (button stuck) → Replace Manual Override Button  M970784-0020A
→ ☐ Yes (button free) → Continue to sensor flash check below
Does sensor flash for 5 seconds?
→ If NO: Replace Power Supply or Battery. Issue resolved?  ☐ Yes  ☐ No →
→ Inspect wiring for breaks / corrosion. Replace Sensor. Issue resolved?  ☐ Yes  ☐ No → Escalate
Push Manual Override — does unit flush?
→ ☐ Yes → Inspect piston & o-ring. Replace Solenoid & Piston Assembly  M970694-0070A
→ ☐ No  → Replace Manual Override Button  M970784-0020A

Water Hammer

Static pressure > 80 PSI (checked at valve)?
Water hammer arrestors installed at correct locations?
Is a Pressure Reducing Valve (PRV) installed?
Does hammering stop when holding the manual override button?
→ If YES → pressure surge confirmed. Install PRV + hammer arrestor per IDAM instructions
→ If arrestor installed but hammer persists → Replace piston with slow-close version  M570619-0070A

Intermittent  /  Ghost Flushing

Type:  ☐ Ghost flush (flushes when no one present)  ☐ Missed flush (no flush after use)
Detection zone checked / adjusted using sensor remote?
→ Ghost flush → Decrease level below 14 to reduce range away from reflective surfaces
→ Missed flush → Increase level above 14 to widen detection zone
Possible reflections present? (mirrors, hi-vis vest, shiny partitions, polished floors)
Objects or signage blocking the sensor face?
